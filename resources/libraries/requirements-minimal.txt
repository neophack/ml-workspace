# Target GPU: NVIDIA V100 (sm_70) through Blackwell (sm_120).
#
# IMPORTANT: do NOT pin/upgrade torch, torchvision, numpy, or any package already
# provided by the NGC image. Upgrading them via pip would replace the NGC-optimized
# build (torch 2.7.0a0+nv25.3, built for sm_70–sm_120) with stock PyPI wheels that
# dropped sm_70, breaking V100 support.
#
# Most utility packages are already installed in the NGC base (numpy, pandas, scipy,
# matplotlib, pillow, requests, tqdm, etc). We install WITHOUT version pins and
# WITHOUT --upgrade, so pip leaves already-satisfied packages untouched and only
# installs what's genuinely missing. This avoids ResolutionImpossible conflicts
# between our pins and the NGC-installed versions.
