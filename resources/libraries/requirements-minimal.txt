# Minimum requirements — Python 3.12 + PyTorch 2.7 (nvcr.io/nvidia/pytorch:25.03-py3).
# Target GPU: NVIDIA V100 (sm_70) through Blackwell (sm_120).
#
# IMPORTANT: do NOT pin/upgrade torch, torchvision, numpy, or any package already
# provided by the NGC image. Upgrading them via pip would replace the NGC-optimized
# build (torch 2.7.0a0+nv25.3, built for sm_70–sm_120) with stock PyPI wheels that
# dropped sm_70, breaking V100 support.
#
# All packages are UNPINNED and installed without --upgrade. pip's resolver leaves
# already-satisfied NGC packages untouched (numpy, pandas, scipy, matplotlib, pillow,
# safetensors, einops, tensorboard, scikit-learn, pydantic, psutil, etc are all
# preinstalled by NGC) and only installs what's genuinely missing. This avoids the
# ResolutionImpossible conflicts that occur when our pins disagree with NGC versions.
